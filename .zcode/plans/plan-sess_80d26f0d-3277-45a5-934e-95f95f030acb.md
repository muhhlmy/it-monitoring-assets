# Rencana: Bintang CSAT Fill + Visualisasi Grafik CSAT di Dashboard

## Tujuan
1. **Bintang CSAT Fill** — bintang rating pakai warna solid (filled), konsisten dengan `TicketCaspRating.vue` (Material Symbol `star` + class `fill-1`, warna amber `#FFAE1F`). Akan dijadikan komponen kecil reusable agar bisa dipakai di dashboard.
2. **Visualisasi Grafik CSAT di Dashboard** — section baru berisi kartu rata-rata CSAT + bar chart distribusi rating (1–5 bintang).
3. **Akses sesuai role** — admin/superadmin lihat CSAT semua; user biasa lihat CSAT tiket miliknya sendiri (konsisten dengan access control `getTicketStats`).

---

## Perubahan (4 file baru/edit)

### 1. (BARU) Backend controller `getTicketCaspStats` — `backend/src/controllers/ticketController.js`
Tambah endpoint agregasi CSAT. Reuse pola role-filter dari `getTicketStats` (line 243-262) untuk `WHERE` clause:
- **Admin/superadmin**: agregasi semua `ticket_casp_ratings`.
- **User biasa**: filter berdasarkan `reporter_user_id = userId` (CSAT tiket miliknya).

Query mengembalikan:
```js
{
  averageRating: number (2 desimal, 0 kalau kosong),
  totalRatings: int,
  distribution: [{ rating: 1, count: n }, ... { rating: 5, count: n }]  // selalu 5 baris
}
```
Gunakan `AVG(rating)`, `COUNT(*)`, dan `COUNT(CASE WHEN rating = k THEN 1 END)`.

### 2. (BARU) Route — `backend/src/routes/ticketRoutes.js`
Tambah `ticketRouter.get('/casp/stats', getTicketCaspStats)` (di atas `/:id` agar tidak tertangkap param).

### 3. (BARU) Komponen `CsatStars.vue` — `frontend/src/components/tickets/CsatStars.vue`
Komponen kecil reusable untuk bintang filled:
- Props: `value` (Number, 0–5), `size` (default `'24px'`), `showValue` (Boolean).
- Pakai pola yang sama persis dari `TicketCaspRating.vue`: `material-symbols-outlined` + `fill-1` + `text-[#FFAE1F]` untuk filled, `text-[#CBD5E1]` untuk kosong.
- Refactor `TicketCaspRating.vue` agar pakai komponen ini (2 tempat: line 84-91 read-only display, line 126-131 input — input tetap interaktif, hanya read-only yang diganti komponen untuk konsistensi).

### 4. (BARU) Komponen `CsatDashboardSection.vue` — `frontend/src/components/charts/CsatDashboardSection.vue`
Section CSAT dashboard, meniru pola komponen chart existing (`AssetTypeBarChart.vue` + `BaseChartCard.vue` + `useChartTheme.js`):
- **Fetch data** via `useApi().get('/api/tickets/casp/stats')` (endpoint baru). Tangani empty/error/loading.
- **Kartu rata-rata CSAT** (kiri): angka besar (mis. `4.6`) + `<CsatStars :value="averageRating" />` + total ulasan + label ("Puas"/"Sangat Puas" dll).
- **Bar chart distribusi** (kanan, `BaseChartCard`): 5 bar (bintang 1–5), tinggi = count. Pakai `Bar` dari vue-chartjs + register modul. Warna gradasi amber (1=merah → 5=hijau) atau palette amber konsisten.
- Layout: grid 12 kolom (kartu `lg:col-span-5`, chart `lg:col-span-7`), konsisten dengan dashboard.
- Empty state: kalau `totalRatings === 0` → tampilkan pesan "Belum ada penilaian CSAT" (jangan render chart kosong).

### 5. (EDIT) `frontend/src/views/DashboardView.vue`
- Import `CsatDashboardSection`.
- Render section baru setelah Row 3 (Bar + Pie chart aset), sebelum "Sebaran Lokasi Aset". Letak logis karena CSAT berkaitan dengan tiket.
- Section terpisah sendiri (tidak mencampur dengan chart aset) supaya jelas.
