## 1. Root Cause Analysis

### P0: E2E Authentication Locator Ambiguity

**Root Cause:** `getByLabel(/kata sandi/i)` regex matched two accessible elements:

1. `<label for="password">Kata sandi</label>` — the password input label
2. `<button aria-label="Tampilkan kata sandi">` — the password visibility toggle button

Playwright strict mode threw `strict mode violation` because the locator resolved to 2 elements. This caused `fill()` to fail silently, which was then caught by the fallback `{ cookies: [], origins: [] }` pattern, producing empty auth state files.

**Impact Chain:**
- 13/28 tests failed (original 28-test suite)
- All 3 auth state files were empty
- RBAC tests became false positives (tests checking for *absence* of admin elements passed even when the user was stuck on `/login`)
- The `catch {}` block in `global-setup.js` line 37-39 silently swallowed the error
